<h2>🎮 Game Modes</h2>
<ul>
  <li><strong>🔍 Algorithmic Solver:</strong> Watch as 4 powerful pathfinding algorithms (DFS, BFS, Dijkstra, A*) navigate complex mazes.</li>
  <li><strong>🕹️ Manual Mode:</strong> Control the player yourself and try to find the goal in procedurally generated labyrinths.</li>
</ul>

<h2>🗺️ Maze Features</h2>
<ul>
  <li>✔️ Randomly generated mazes in 3 sizes: 21x21, 41x41, 61x61</li>
  <li>✔️ Clearly visualized paths: Blue for visited tiles, Green for the optimal solution</li>
  <li>✔️ Live timer that tracks solving time</li>
  <li>✔️ Visual and audio feedback upon completion</li>
</ul>
