#Path Finder X [Done]
🧠 PathFinder X
A Maze Solver Experience Powered by Algorithms
PathFinder X blends educational depth with puzzle-solving thrill. Whether you're into AI pathfinding or just love a good maze, this experience is designed to challenge and inspire.

🎮 Game Modes:
🔍 Algorithmic Solver: Watch as 4 powerful pathfinding algorithms (DFS, BFS, Dijkstra, A*) navigate complex mazes.
🕹️ Manual Mode: Control the player yourself and try to find the goal in procedurally generated labyrinths.
🗺️ Maze Features:
✔️ Randomly generated mazes in 3 sizes: 21x21, 41x41, 61x61
✔️ Clearly visualized paths: Blue for visited tiles, Green for the optimal solution
✔️ Live timer that tracks solving time
✔️ Visual and audio feedback upon completion
🎨 Aesthetic:
Clean futuristic UI
Subtle particle effects and ambient music
Smooth transitions between menus and game scenes
Neon-style minimalist art direction
🧩 Ideal for:
Developers curious about pathfinding algorithms
Puzzle lovers who want something unique
Gamified learning experiences
Casual players who want to test their logic
